# Project Headers

This directory contains reusable header files for various C/C++ projects. Each header provides common functionality that can be included in your projects to speed up development.

## Contents

- **file.h**  
  Provides file handling utilities such as file input/output operations, file management, and helper functions for working with files in C/C++.

- **screen.h**  
  Contains functions for managing screen output, such as clearing the console, setting cursor position, or formatting output to the terminal.

- **time.h**  
  Offers time-related utilities, including functions for retrieving the current time, formatting time strings, measuring elapsed time, and scheduling tasks.

## Usage

Include the desired header file in your project source code:
```c
#include "file.h"
#include "screen.h"
#include "time.h"
```
